# ✨ Hover

A collection of interactive **CSS hover effects** built with HTML, CSS, and JavaScript. This project showcases creative hover animations and transitions applied to buttons, cards, images, and other UI elements — great as a reference or a drop-in effects library for other projects.

---

## ✨ Features

- 🎨 **Custom Hover Animations** — Smooth CSS transitions and transforms on mouse hover
- 🖱️ **Interactive Elements** — Buttons, cards, and/or images that respond to user interaction
- ⚡ **Lightweight** — Pure HTML, CSS, and vanilla JavaScript with no external frameworks
- 📱 **Responsive Design** — Effects render consistently across screen sizes
- 🧩 **Reusable Components** — Easy to copy individual hover effects into other projects

## 🚀 Local Setup and Installation

Follow these steps to run the project on your local machine:

### 1. Clone the repository

```bash
git clone https://github.com/nikita-sharma-codes/hover.git
cd hover
```

### 2. Open the project

Simply open `index.html` in your browser:

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

Or, for a live-reload experience, run it with a local development server (e.g. the VS Code "Live Server" extension) and open the URL it provides, typically **http://127.0.0.1:5500/**.
